# Create Pull Request (Cursor)

Cursor entry point — **do not duplicate instructions here.**

Read and follow the canonical command:

**`.claude/commands/create-pr.md`**

Opens a **draft** PR against `main` with the Fluent template, `Refs #NNN` (or
in-session `Refs: none` for approved no-ticket chores), one `code-reviewer`
pass, Project 4 **In PR Review** when ticketed, and CI watch to green. Never
merge.

`/open-pr` is an alias of this command.

Usage: `/create-pr` (optional targeted test path).
