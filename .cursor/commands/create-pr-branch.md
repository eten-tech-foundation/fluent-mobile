# Create PR Branch (Cursor)

Cursor entry point — **do not duplicate instructions here.**

Read and follow the canonical command:

**`.claude/commands/create-pr-branch.md`**

Branch-only: `{author}/{type}/{issue-number}-{slug}` from a GitHub issue, or
`{author}/chore/{slug}` for an in-session approved no-ticket chore
(`Refs: none`). For the full issue → implement → PR loop, use **`/start-issue`**.

Usage: `/create-pr-branch 173`
